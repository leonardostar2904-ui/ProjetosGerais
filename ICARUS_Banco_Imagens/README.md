# ICARUS: Banco de Imagens de Apoio para Social

50 imagens geradas no Higgsfield (modelo GPT Image 2.5), formato 4:5. Os scripts padronizam tudo em **1080x1350 px (PNG)**.

## Como baixar tudo organizado (1 comando)

**Mac/Linux:** abra o Terminal nesta pasta e rode `bash baixar_e_organizar.sh`

**Windows:** clique com o botão direito em `baixar_e_organizar.ps1` e escolha *Executar com PowerShell*

O resultado é a pasta `ICARUS_Imagens/` com a estrutura abaixo e o arquivo `ICARUS_Imagens.zip`.

Se preferir baixar manualmente, todos os links estão na tabela abaixo (eles também ficam salvos na sua conta Higgsfield, em Histórico).

## Observações

- **#11** foi bloqueada pelo filtro de conteúdo na primeira tentativa (anatomia de costas humanas). Foi regerada como estudo de máquina de voo estilo Da Vinci, mantendo o conceito de "pontos de fixação das asas".
- Aos prompts originais foram adicionados reforços de estilo: paleta da marca, grão de filme, "sem logos, sem marca d'água, sem cara de banco de imagem".
- Stories (9:16) não foram gerados. Cortar 4:5 para 9:16 perde muita largura, então o ideal é gerar à parte.
